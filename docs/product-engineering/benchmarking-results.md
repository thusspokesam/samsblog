## Result record

For each run capture:

- Objective and comparison baseline.
- Server, accelerator count, memory, network, and storage configuration.
- BIOS settings, power profile, OS, kernel, firmware, driver, runtime, and container image digest.
- Dataset or model version, batch size, precision, concurrency, and test parameters.
- Warm-up, repetitions, run duration, and environmental conditions.
- Raw results, summary statistics, variability, errors, and telemetry.
- Reviewer, approval decision, limitations, and evidence location.
